# Lang tutor docs

Start here. What the app is, how to set it up, and how each language is served are in the root [`README.md`](../README.md).

- [`ARCHITECTURE.md`](ARCHITECTURE.md): the first read before changing code. It has the Task Index (which files to read for a change), the layers, the integration footguns and where the tests are.
- [`lsp.md`](lsp.md): language-server bridge decisions and caveats.
- [`learner-memory.md`](learner-memory.md): what the tutors remember about the learner and how it is merged.
- [`plans/MAIN.md`](plans/MAIN.md): a generated snapshot of the plan. Every task is a Linear issue in team LANG, grouped into projects (waves); the snapshot is regenerated from Linear and never edited by hand.
- [Glossary](../README.md#glossary): terms the docs and plans use in a project-specific sense.
- [`../CLAUDE.md`](../CLAUDE.md): run commands, coding rules and gotchas for agents.
